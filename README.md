# TP QR

TP QR 是一个面向简体中文用户的动态二维码平台，计划支持文本、网址、云端图片、业务表单和批量实体二维码。创建者可以编辑草稿并发布新版本，已经打印的二维码无需更换。

## 当前状态

项目目前处于设计驱动流程的第二阶段，尚未初始化前端、Worker、数据库或依赖清单。已完成 11 张个性化页面参考图以及逐页素材拆解；开始编写业务代码前，仍需确认并生成关键图片素材。

已确认的视觉方向为“二维码发布档案系统”：近黑舞台、暖色档案纸、超大压缩排版、切角文件、撕边凭证、钴蓝校准线，以及青色成功和红色异常状态。

## 开发与 Git 约定

- 功能分支使用 `feat#<序号>_<提交人>_<修改内容>` 格式。
- 每个提交只记录一个可说明、可复现的逻辑阶段，生成缓存、测试截图和归档内容不进入 Git。
- 功能验证通过后再合并到 `main`。
- 当前尚无可执行的安装、构建或测试命令；工程初始化后会在此补充完整的克隆、环境配置、本地运行、测试、构建、Cloudflare 部署和域名接入流程。
